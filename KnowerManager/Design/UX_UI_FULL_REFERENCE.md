# Полный UX/UI Reference

Вся дизайн-система собрана в папке `KnowerManager/Design/` для удобного редактирования.

## Файлы

1. **DesignTokens.swift** — Базовые токены (spacing, radius, typography, shadows)
2. **NeonTheme.swift** — Цветовая палитра, статусные цвета, акценты (AppThemeTokens)
3. **Components.swift** — Базовые стили кнопок, карточки, инпуты
4. **UXUIKit.swift** — Комплексные UI-компоненты (табы, карточки фич, статус)
5. **ModernUI.swift** — Современные секции и карточки (ModernSection, ModernCard)
6. **DesignKit.swift** — Утилиты и модификаторы
7. **UXUI_README.md** — Документация и примеры

## Принципы дизайна

- **Чистота**: минимум визуального шума, фокус на ключевом действии
- **Состояния**: чёткая индикация (активен/неактивен, защищён/отключён)
- **Иерархия**: важное — первично, вторичное — приглушено
- **Консистентность**: единые токены во всём приложении
- **Доступность**: адекватный контраст, понятные иконки

## Основные значения

- Отступы: 4,8,10,12,14,16,18,20,24
- Скругления: 8,10,12,14,16,18,24
- Типографика: системная, сбалансированные веса

## Редактирование

Любые изменения в токенах автоматически влияют на все компоненты. Рекомендуется править именно файлы в Design/, а не дублировать стили.
